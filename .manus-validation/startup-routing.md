# Startup Routing Validation

- The root path (`/`) renders the independent **Login** screen with Google sign-in, disabled Apple coming-soon state, email/password fields, and a Create one link.
- The `/signup` path renders a distinct **Create your account** screen with name, email, password, confirmation, password-strength guidance, Google sign-up, disabled Apple coming-soon state, and a Log in link.
- These checks were completed in the active preview on 2026-08-16.
